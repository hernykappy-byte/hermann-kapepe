# Question audit

How the 292 questions added on 2026-10-26 were checked. The first 170 were hand-written and fact-checked in October (13 faulty items fixed; see GATE_REPORT.md).

Process: written by one set of agents, then reviewed by a second set, then every question containing a date, number or "first/largest/only"-style claim was checked against fetched source pages by a third set. Wording the sources did not support was fixed or the question was dropped. Exact duplicates of the bank were removed automatically.

| Level | Count | Meaning |
|---|---|---|
| Source-verified | 163 | A fetched page supported the answer and the fact line (fact lines were corrected where it did not) |
| Reviewed only | 100 | No dates, numbers or superlatives; reviewed by a second model, not source-checked |
| Unsourced | 29 | Textbook facts the source check ran out of budget on; reviewed by a second model only. Spot-check these first |

Models reviewing models is not independent proof. A person should spot-check, starting with the unsourced list.
